Priority issue register

Search and filter findings; expand a row for impact and fix direction. Evidence details in the full report.

T1HIGH JSON Feed endpoint serves unrendered Liquid
URL: /articles/feed.json

Live response contains Liquid syntax (`{{…}}`, `{% for…%}`), not JSON. Make Jekyll render the feed, validate JSON Feed 1.1 and response content type, or remove the advertised link. Priority P1.

T2HIGH Invalid shared Organization JSON-LD
URL: all non-home pages using shared head include. Extra closing syntax invalidates the block; BlogPosting publisher references depend on this entity. Correct braces and parse all rendered JSON-LD in CI. Priority P1.
T3HIGH* Nov 22 repository article not in live discovery assets
URL: candidate Nov 22 article. Live archive/feed/llms/sitemap observed through Nov 21. Confirm publish intent, fix local post defects, deploy, then verify URL and discovery assets. Conditional on intended publication. Priority P1.
T4MEDIUM Candidate post has missing hero path and unmatched author key
Repo front matter points to a missing `google-deep-review-header.webp`; author key “F9XR Team” does not match registry key; conclusion appears before content sections. Fix before deployment.
T5MEDIUM Sitemap contains unverified `/auth` and skill-file entries
Live sitemap lists `/articles/auth` and three `.well-known/agent-skills/.../SKILL` locations. Check HTTP status, canonical and robots; exclude only if redirect/noindex/non-indexable or not intended for search.
T6MEDIUM LocalBusiness schema needs truth/scope validation
Shared source emits address, phone, geo, hours and priceRange across non-home pages. The audited property is a global editorial site. Confirm these describe an eligible real business and are visible; local schema may belong on agency location pages.
T7MEDIUM Topic taxonomy is over-fragmented
Archive shows 725 labels across 158 posts, with near duplicates. Consolidate controlled topic hubs; no indexation penalty asserted. Priority P2.
T8MEDIUM Analytics and privacy implementation needs behavior audit
Source config references GA, GTM, GoatCounter and Grow.me. Verify actual tag firing, cookies, duplication, consent and policy disclosure before making legal conclusions. Priority P1 owner review.
T9MEDIUM · RISK CSS, font swap, preload and injected-widget performance risks
Two render-blocking stylesheets and an unused OG-image preload; Translate UI injects into an empty element. These are source risks only. PSI request hit API quota 429; measure with Lighthouse/CrUX before changes.
O1LOW Homepage may repeat some posts across category groups
Text extraction shows repeated cards, potentially intentional category tabs. Verify rendered tab behavior before changing. UX polish only.
D1DATA GAP Search rankings/indexing, backlinks, CWV and AI citations unavailable
No GSC/CrUX/backlink export or platform prompt experiment. Do not infer “not indexed,” “no backlinks,” “poor CWV,” or “no AI citations.” Instrument and gather baselines.
