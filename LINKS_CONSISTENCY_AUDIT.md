### Inconsistencies found

| # | Finding | Severity | Detail / fix |
|---|---|---|---|
| C1 | **Feed/sitemap/llms.txt live inventory trails the repo (stale cache)** | High | `main == origin/main` (everything pushed), yet live still shows content only through 21 Nov and `feed.json` raw. The BOM (B2) explains feed.json; for the rest, f9xr.org is Cloudflare-fronted (`/cdn-cgi/` markers present) — **purge the Cloudflare cache / reduce HTML+XML cache TTL** after deploying the current fixes, then verify sitemap, llms.txt, RSS and the Nov 22 post go live. |
| C2 | **Pinterest configured but unlinked** | Low | `_config.yml` sets `pinterest_username: "f9xr"`, but neither `sameAs` nor the footer links Pinterest. Either add `https://pinterest.com/f9xr` to both `sameAs` blocks + footer, or drop the config key if the profile is inactive. (Left as-is: owner should confirm the profile is real/active first.) |
| C3 | **External hero-image hotlink** | Low | `_posts/2026-08-02-google-ai-content-guidance-fact-check-update.md` uses a raw `images.unsplash.com` URL as its `image:` (OG/Twitter image + hero). Works, but hotlinks are fragile (Unsplash can drop/alter the asset) and it bypasses your `-640.webp` variant convention. Recommend downloading it into `assets/post-images/` and generating the 640 variant. |
| C4 | **Category label drift** | Low | 16 distinct `category:` strings across 159 posts (e.g. "AI Search News" vs "Google Maps, Local SEO, AI Search News"). Harmless because every post sets an explicit permalink, but it weakens topic hub signal — fold into the planned taxonomy consolidation (audit item T9). |
| C5 | **Feb 2026 posts' dates render inconsistently in feeds?** | Verified OK | All feed timestamps use `date_to_xmlschema` with site `timezone: UTC` — consistent. No action. |

### Entity/data consistency verdict

With today's fixes applied, the machine-readable identity graph is internally consistent: one phone, one email, five registry authors ↔ five author pages ↔ front matter, unique titles/descriptions, canonical permalinks everywhere, and complete `sameAs` (modulo the Pinterest question). The remaining inconsistency is **delivery-layer** (C1: stale live cache), not data-layer.
